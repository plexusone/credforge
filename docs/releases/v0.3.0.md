# v0.3.0

**Release Date:** 2026-11-20

## Highlights

- **Review every credential on one page.** `credforge review` serves a
  page on this machine listing each credential with its stores,
  consumers, entitlements, rotation and events. Filter by system,
  environment, status, store, sensitivity, log state, live state and
  decision, and run the live check from the page to see each store's
  state and the stores no credential names.

## Added

- `credforge review` and `cli.Review(cli.Options)`, served on a loopback
  address only (`--addr`, default `127.0.0.1:8484`). Decisions are saved
  in the reviews file (`--reviews`, `Options.ReviewsPath`, default
  `reviews.json`); events in the event log. `--by` names the reviewer.
- `review.File`: the reviews file, one decision per credential ID or store
  key (`type:account:path`): `approved`, `change` with a note, or
  `remove`. Its JSON Schema is generated from the Go types.
- `review.Server`: the page and its API. It answers only to a loopback
  Host, accepts only same-origin JSON writes, and serves the page under a
  strict content security policy. It never writes the registry and never
  reads a value.

```go
opts := cli.Options{Registry: buildRegistry, Targets: buildTargets, ReviewsPath: "reviews.json"}
credentials.AddCommand(cli.Check(opts), cli.Review(opts))
```
