# v0.6.0

**Release Date:** 2026-11-21

## Highlights

- **The setup list follows the registry's setup guidance.** What is
  needed for launch comes first, and each item comes after what it
  requires:
    - **Prerequisites** at issuers, such as a cloud project or a consent
      screen, with their steps and how to tell they are done.
    - **Run once** cards: a tool that makes several credentials shows its
      command once, before the first credential it makes.
    - On each card, what to set up first, the configuration changes, the
      issuer's mode and who grants each entitlement.

## Added

- A **Needed** filter: for launch, later, optional or only during a
  rotation.
- The registry's advice, under the summary.
- The new fields in each credential's details.

## Changed

- A credential a tool makes counts as set up by whoever runs the tool's
  command. One needed only during a rotation is left out of the setup
  list.
- Requires systemspec-credential v0.3.0.

## Upgrading

No change is needed. A registry without the new fields shows as before,
in registry order.
