# v0.9.1

**Release Date:** 2026-11-22

## Changed

- **The setup runbook says how to use it.** Its "How to use it" section,
  on every rendered page, now covers:
    - what to record before the first run, so the steps already done show
      as done: `check --include-planned --record`;
    - the access its commands use: a GitHub token in `GITHUB_TOKEN` or
      `GH_TOKEN`, and an AWS profile in `AWS_PROFILE`;
    - what `setup run <step>` does, and how to record a step done by hand
      with `setup record <step> done`;
    - how to check every step with `setup verify`, and to commit the
      progress log with the event log.

## Upgrading

No change is needed.
