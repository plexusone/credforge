# v0.11.1

**Release Date:** 2026-11-25

## Highlights

- **A rotation-only credential is never missing.** A check, or a deploy's
  preflight built on `Compare`, no longer fails on a credential that exists
  only while another rotates.

## Fixed

- `Compare` reported a credential with `need: rotation`, such as a
  verification secret kept beside a new HMAC secret, as `missing` whenever
  no rotation was under way. It also reported a credential with
  `need: optional` as missing unless it was tagged `optional` too. Both are
  now treated as an optional tag is: never `missing`, and reported once a
  store holds them.

## Documentation

- The README and Getting Started say which credentials are never missing.

## Upgrading

No change is needed. A check that failed on a rotation-only credential
passes.
