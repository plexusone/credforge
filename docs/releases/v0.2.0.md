# v0.2.0

**Release Date:** 2026-11-20

## Highlights

- **Mount the check beside your own commands.** `cli.Check` returns the
  `check` command alone, so a host tool adds it to a command tree it
  already has, such as the one systemspec-credential's `cli.New` returns.

## Added

- `cli.Check(cli.Options)`: the check command with its own `--registry`
  (when `Options.Registry` is nil), `--events` and `--targets` (when
  `Options.Targets` is nil) flags. They take precedence over a parent's
  flags of the same names, so the check reads and records in the event log
  its own `--events` names.

```go
credentials := credspeccli.New(credspeccli.Options{Use: "credentials", Registry: buildRegistry})
credentials.AddCommand(cli.Check(cli.Options{Registry: buildRegistry, Targets: buildTargets}))
```

`cli.New` is unchanged.
