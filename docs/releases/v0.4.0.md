# v0.4.0

**Release Date:** 2026-11-20

## Highlights

- **See who handles each credential.** The review page's Handled by
  column shows who generates, distributes and rotates each credential, in
  that order: a human operator, an agent operator (an AI agent acting
  for an operator) or a program (a deterministic tool such as a deploy
  tool or a CI workflow). Hover it for each stage by name, and filter by
  it: the filter matches a credential when any of its stages is handled
  that way.

## Dependencies

- systemspec-credential v0.2.0, whose registries may say an `agent`
  handles a stage, beside `human` and `system`.

## Documentation

- The README lists the access the live check needs: a GitHub token that
  can list each repository's Actions secrets, and AWS credentials with
  `ssm:DescribeParameters`. Both read names and dates, never values.

## Upgrading

No change is needed. Registries that use only `human` and `system` load
as before.
