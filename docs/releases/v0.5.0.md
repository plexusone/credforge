# v0.5.0

**Release Date:** 2026-11-20

## Highlights

- **A setup list of what is left to do.** The review page's **Setup
  list** shows each credential left to set up, grouped by system and
  environment:
    - **Get it from:** the issuer, its console, and the command or steps
      that make the value.
    - **It may:** its entitlements.
    - **Put it in:** each store, with its install command and live state.

## Added

- A **To set up by hand** tile that opens the setup list of what a person
  sets up, a **Table / Setup list** switch, and a **To set up by** filter.
  A credential is left to set up when the live check finds a store
  missing its value, or when it is planned and no store is found holding
  one. Without a live check, every planned credential is listed.
- The setup list prints cleanly, one credential per card.

## Upgrading

No change is needed.
