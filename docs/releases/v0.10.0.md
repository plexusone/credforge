# v0.10.0

**Release Date:** 2026-11-22

## Highlights

- **The setup runbook opens with what it sets up**, so a person sees at a
  glance what is theirs to do and what is theirs to review:
    - A count of the credentials by need, of those you create and set,
      and of those tools you run make and store, with the prerequisites
      at issuers.
    - A table for each group, in step order: **you create and set
      these**, **tools you run make and store these; review them**, and
      anything set up otherwise.

## Added

- Each row of the tables gives:
    - when it is needed and how it is made;
    - who creates it, and at which issuer and account, such as "you, at
      github example-org";
    - who sets it, and in which stores, such as "you, with install, in
      aws-ssm hosting", then what the deploy does with it: copies it to
      the host, or passes it to a process such as a migration only;
    - the step that sets it up, linked;
    - what it shares with other systems: the same issuer account, such
      as one GitHub organization or one database server, or another
      system's credential it needs.

## Changed

- The usage section's commands are code blocks, so each can be copied as
  it is.
- Requires systemspec-runbook v0.2.0: HTML pages built with templ, full
  width, with a copy button on every command.

## Upgrading

No change is needed. A host that places the HTML fragment in its own page
adds systemspec-runbook's `Script` after it for the copy buttons.
